# Disciplina---AplicacoesWeb
Exercícios propostos resolvidos

Ideia Geral das aulas:

//Uma página web é estruturada, basicamente, com HTML, CSS e JavaScript.
//O HTML é o que estrutura a página, o CSS estiliza, e o JS faz as coisas funcionarem, com a lógica de programação;
//Em toda a página de HTML temos o DOM, que é a árvore de elementos que o navegador monta a partir do HTML. É nele que o JS "mexe" para fazer as coisas funcionarem para o usuário dentro do site;
//Na linguagem JS podemos declarar variáveis com const, let e var. Porém, como var tem escopo global, o que o deixa mais suscetível à bugs, é preferível utilizar o const e o let.
//Como próprio nome indica, const, é para referências que não mudam, como para elementos do DOM. E let para valores que mudam, como contadores.
//Seleção de elementos, pode ser realizada com getElementById. Então, como o próprio nome refere, quando usamos ele seletor referenciamos o elemento pelo ID. 
// Porém, como tem elementos que não vão ter ID, que vão ter classes ou tags, é preferível usar o querySelector, e o querySelectorAll, pois assim conseguimos referenciar não apenas pelo ID, e nem apenas um, mas uma classe.
